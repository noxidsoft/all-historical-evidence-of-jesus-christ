# Extracanonical Texts

Every file here is public domain: the gospels.net translations below and the older Gutenberg/CCEL editions. Texts with no free translation are listed in the registry with "—". Canonical status, dates, and manuscript witnesses for each text are in [GOSPEL-REGISTRY.md](../../GOSPEL-REGISTRY.md).

## Modern public-domain translations ([gospels.net](https://www.gospels.net/))

All are by Mark M. Mattison. Each translator dedicated his work to the public domain: "may be freely copied and used, changed or unchanged, for any purpose." Each file starts with an HTML comment giving its source URL and translator. Affiliate-link paragraphs from the website are removed. Translator notes are kept.
